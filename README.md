# Kanban

A simple Kanban board built with React, TypeScript, and Tailwind CSS.

## Features

- Drag and drop cards between columns
- Create, edit, and delete cards
- Persistent storage

## Tech Stack

- React 19
- TypeScript
- Vite + SWC
- Tailwind CSS v4

## Development

```bash
pnpm install
pnpm dev
```

## Build

```bash
pnpm build
```
